# 小手机 · SillyTavern 独立安装版

安装地址：

```text
https://github.com/ike888-go/sese-phone
```

这是 2026-10-25 源码阅读包的安装适配预发布版。根目录包含酒馆扩展清单和已编译浏览器文件，安装者不需要 Node.js，也不需要自行构建。

## 安装

1. 安装并启用[酒馆助手](https://github.com/N0VI028/JS-Slash-Runner)：在酒馆的「扩展 → 安装扩展」中粘贴它的仓库地址。
2. 在同一个「安装扩展」窗口粘贴本仓库地址。
3. 停用以前导入的同名酒馆助手脚本，刷新酒馆页面。
4. 进入角色聊天。扩展设置里的「小手机 · 安装状态」可查看依赖或装载错误。

小手机提供聊天、通话、社媒、商城等手机界面。建议先安装统一状态栏，并使用瑟瑟台账或兼容数据库作为角色资料来源；缺少共享配置、表格或状态栏桥时，部分联动不可用。

## 三个仓库分别安装

| 模块 | 独立仓库 |
| --- | --- |
| 统一状态栏 | https://github.com/ike888-go/sese-unified-statusbar |
| 小手机 | https://github.com/ike888-go/sese-phone |
| 瑟瑟台账 | https://github.com/ike888-go/sese-ledger |

推荐安装顺序：酒馆助手 → 统一状态栏 → 瑟瑟台账 → 小手机，全部装完刷新页面。每个仓库只启动自己的模块，更新与卸载分别在酒馆扩展管理中操作。源码构建依赖中包含其他模块的公共文件，这是原代码的复用关系，不代表捆绑启动。

## 验证范围与使用限制

- 已准备：单模块构建、清单和文件引用检查、装载器模拟测试、原始源码校验。实际结果见对应 GitHub Release。
- 尚未验证：目标用户酒馆版本、真实安装与 UI、AI 生成、世界书写入、聊天切换、保存恢复、长时间运行及可选生图/语音服务。预发布不等于完整真机验收。
- 装载器检查实际 API 能力；清单最低入口版本为 1.13.0，不代表该版本所有功能都已验证。接口核对来源见 [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)。
- 原模块并无完整热卸载：禁用、更新或卸载后刷新页面。卸载文件不等于删除此前保存的聊天相关数据。
- AI、生图、语音使用原模块配置，可能向你选择的模型或服务发送相关内容；本安装适配不添加独立后端。
- 原项目含成人向内容，请仅在合适的受众与场景使用。

## 开发

使用 Node.js 22.12+（CI 使用 Node.js 24）：

```sh
npm ci
npm run build
npm test
npm run check
```

发布时必须把 dist/ 产物一并提交，否则酒馆不能直接安装运行。
