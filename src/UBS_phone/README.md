# UBS_phone（小手机）

入口：`index.ts` + `index.html`。手机壳在 Shadow DOM 内自行挂载。

## 目录

- `core/`：微信、电话、社媒、窥私、不夜城、游戏中心、商城、语音、生图、存档等引擎
- `renderers/`：手机壳、各 App、弹层与共用 UI
- `styles/`：手机主题与皮肤变量

## 与主扩展的关系

小手机通过顶层窗口桥读取主扩展的世界状态与配置，不直接 import 主扩展的有状态模块。构建时作为独立 webpack 入口产出。

## 说明

源码阅读副本未包含测试、内部设计文档、皮肤示例与历史打包产物。
